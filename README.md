# Vulto OS

**Built on Arch Linux. Designed for freedom. Made to evolve.**

Vulto OS is an Arch Linux-based Linux distribution designed to provide a modern, customizable, and versatile computing experience. Combining the flexibility of Arch Linux with the KDE Plasma desktop environment, Vulto OS aims to make powerful Linux tools accessible through a clean desktop experience and a graphical system installer.

> **Status:** Under development. Features and installation procedures may change as the project evolves.

## ✨ Features

- **Arch Linux base** — A flexible foundation for a customizable operating system.
- **KDE Plasma** — A modern, configurable desktop environment.
- **Calamares installer** — A graphical installer planned to simplify system installation.
- **Google Chrome** — Included as the default web browser.
- **System and recovery tools** — Utilities intended for system maintenance and troubleshooting.
- **Customization** — A foundation for future editions tailored to different needs.

## 🎯 Project Goals

Vulto OS aims to develop into a versatile Linux distribution suitable for different workflows, including:

- **Vulto Daily** — Everyday computing and general use.
- **Vulto Dev** — Software development and technical workflows.
- **Vulto Gamer** — Gaming and entertainment.
- **Vulto Ultimate** — A comprehensive edition combining tools for multiple use cases.

These editions are planned concepts and may change during development.

## 🖥️ Desktop Environment

The initial edition uses KDE Plasma, offering a familiar graphical desktop with customizable panels, application menus, system settings, and desktop workflows.

## 🛠️ Technology

- **Base:** Arch Linux
- **Architecture:** x86_64
- **Desktop environment:** KDE Plasma
- **Display manager:** SDDM
- **Installer:** Calamares
- **Boot and installation tools:** Archiso and GRUB

## 🚧 Development Status

Vulto OS is currently in its early development stage. The initial focus is building a bootable ISO, configuring the live environment, integrating the graphical installer, and testing the installation process in a virtual machine.

Not all planned features or editions are available yet. Installation on physical hardware is not recommended until the ISO has been adequately tested.

## 🧪 Testing

Development builds should be tested in a virtual machine before being used on physical hardware.

Testing priorities include:

- Booting in UEFI and legacy BIOS environments where supported.
- Starting the KDE Plasma live session.
- Network connectivity.
- Google Chrome functionality.
- Calamares partitioning and installation.
- Booting the installed system.
- Verifying that live-session settings do not persist in the installed system.
